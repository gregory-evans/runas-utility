# RunAs Utility

Утилита командной строки для запуска программ с **повышением привилегий до администратора** через UAC Windows. Написана на **Free Pascal**, компилируется в самодостаточный `.exe` без зависимостей.

## Возможности

| Функция | Описание |
|---|---|
| **Повышение прав** | Запуск любой команды с правами администратора через UAC (`-a`) |
| **Режимы окна** | Нормальный, свёрнутый, развёрнутый, скрытый (`-n`, `-m`, `-M`, `-h`) |
| **IPC через MMF** | Передача командной строки между процессами через отображаемые в память файлы |
| **Синхронизация** | Windows Event для координации родительского и дочернего процессов |
| **Портативность** | Один `.exe` файл, никаких зависимостей |

## Быстрый старт

### Сборка

```bat
build.bat
```

Или вручную:

```bat
fpc -O3 -CX -XX -Xs run.pas
strip run.exe
```

> **Требования:** Free Pascal Compiler (`fpc`), утилита `strip` (опционально, для уменьшения размера бинарника).

## Использование

```
run.exe [-h | -m | -M | -n] [-a] COMMAND [PARAM1 "PARAM 2" ...]
```

### Параметры

| Флаг | Режим окна | Описание |
|---|---|---|
| `-n` | `SW_NORMAL` | Обычное окно **(по умолчанию)** |
| `-m` | `SW_MINIMIZE` | Свёрнутое в трей |
| `-M` | `SW_MAXIMIZE` | Развёрнутое на весь экран |
| `-h` | `SW_HIDE` | Скрытый запуск |
| `-a` | — | Запуск с правами администратора |
| `-?` | — | Вывести справку |

### Аргументы

| Аргумент | Описание |
|---|---|
| `COMMAND` | Путь к исполняемому файлу или команде |
| `PARAM1 PARAM2 ...` | Параметры, передаваемые команде (строки с пробелами можно взять в кавычки) |

## Примеры

```bat
:: Обычный запуск
run.exe notepad.exe

:: Запуск с правами администратора
run.exe -a cmd.exe

:: Скрытый запуск
run.exe -h -a taskkill /F /IM example.exe

:: Свёрнутый запуск с параметрами
run.exe -m -a powershell.exe "Get-Process"

:: Развёрнутое окно
run.exe -M notepad.exe "C:\file.txt"
```

## Как это работает

### Без повышения прав (`-a` отсутствует)

1. Парсинг аргументов командной строки
2. Непосредственный запуск команды через `CreateProcess`

### С повышением прав (`-a` указан)

1. **Родительский процесс** проверяет текущие привилегии
2. Если прав достаточно → запуск команды напрямую
3. Если прав недостаточно:
   - Создаётся **именованный MMF** (memory-mapped file) с уникальным именем
   - Командная строка записывается в MMF
   - Создаётся **именованный Event** в несигнальном состоянии
   - Запускается **копия себя** через `ShellExecuteEx` с `runas` и маркером `--elevated`
   - Родитель ждёт Event (таймаут 10 сек)
4. **Дочерний процесс** (с правами админа):
   - Открывает и читает MMF
   - Устанавливает Event (родитель продолжает работу)
   - Выполняет команду через `CreateProcess`
   - Освобождает ресурсы

## Коды возврата

| Код | Константа | Описание |
|---|---|---|
| `101` | `ERROR_NO_PARAMETERS` | Не передано параметров |
| `102` | `ERROR_REQUEST_HELP` | Запрошена справка |
| `103` | `ERROR_UNDEFINED_PARAMETERS` | Непонятный флаг |
| `104` | `ERROR_CREATE_PROCESS` | Ошибка создания процесса |
| `105` | `ERROR_CANT_OPEN_SECURITY_TOKEN` | Не удалось открыть токен процесса |
| `106` | `ERROR_CANT_WRITE_MMF` | Ошибка записи в MMF |
| `107` | `ERROR_CREATE_MMF` | Не удалось создать MMF |
| `108` | `ERROR_CREATE_EVENT` | Не удалось создать Event |
| `109` | `ERROR_ON_WAITING_EVENT` | Таймаут ожидания Event |
| `110` | `ERROR_SHELL_EXECUTE` | Ошибка ShellExecute |
| `111` | `ERROR_READ_MMF` | Ошибка чтения MMF |
| `112` | `ERROR_OPEN_MMF` | Не удалось открыть MMF |
| `113` | `ERROR_MAP_MMF` | Не удалось отображить MMF |
| `114` | `ERROR_OPEN_EVENT` | Не удалось открыть Event |
| `115` | `ERROR_SET_EVENT` | Не удалось установить Event |

## Рекомендации по улучшению

### 🔴 Критические

1. **Обработка отказа UAC** — Если пользователь нажмёт «Нет» в диалоге UAC, `ShellExecuteEx` завершится неудачно, но текущая проверка `GetLastError() = 0` ненадёжна. Рекомендуется проверять возвращаемое значение `ShellExecuteExW` и код ошибки более детально.

2. **Гонка ресурсов** — Если дочерний процесс не запустится (например, UAC отключён групповой политикой), родительский процесс заблокирован на 10 секунд. Стоит добавить проверку доступности UAC перед ожиданием.

3. **Безопасность MMF** — Имя MMF основано на `GetCurrentProcessId()`, который может быть предсказуем. В теории другой процесс мог бы создать MMF с тем же именем до вашего процесса. Рекомендуется добавить случайный суффикс (например, через `CryptGenRandom`).

### 🟡 Рекомендуемые

4. **Кодировка** — Проект использует `{$H+}` (UTF-8 по умолчанию), но Windows API вызывается через `*A` (ANSI) версии. Для корректной работы с не-ASCII путями стоит переключиться на `*W` (WideChar) версии функций.

5. **Освобождение ресурсов при ошибке** — В `StartElevationProcess` при ошибке на промежуточном шаге ранее созданные хендлы (MMF, Event) могут не быть закрыты. Рекомендуется использовать `try..finally` или единый блок очистки.

6. **Валидация команды** — Перед запуском стоит проверять существование файла команды (`FileExists`), чтобы выдать понятное сообщение об ошибке.

7. **Поддержка `CREATE_NO_WINDOW`** — Флаг `-h` использует `SW_HIDE`, но для консольных приложений иногда удобнее `CREATE_NO_WINDOW`, который полностью подавляет создание консоли.

### 🟢 Опциональные

8. **Кэш токена** — `IsRunningAsAdmin()` открывает/закрывает токен каждый раз. При многократных вызовах можно кэшировать результат.

9. **Поддержка псевдонимов флагов** — Добавить длинные варианты (`--admin`, `--help`, `--hide`) для удобства.

10. **Логирование** — Для отладки полезно добавить опциональный verbose-режим (`-v`), выводящий промежуточные шаги в stderr.

11. **Тестовый набор** — `hello.bat` демонстрирует парсинг аргументов, но автоматизированных тестов нет. Рекомендуется добавить скрипт, проверяющий основные сценарии.

12. **Continuous Integration** — Простой GitHub Actions workflow для компиляции при каждом push/PR обеспечит раннее обнаружение проблем сборки.
